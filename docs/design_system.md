# 设计与图表系统

暖白纸面、墨绿主色、石墨文字和少量棕色强调。正文采用系统中文无衬线字体，标题采用中文衬线后备字体；不依赖外部字体请求。

颜色与布局变量集中在全局样式，浅色与深色共用同一语义。图表使用主色表达数量，棕色表达区别或注意项，不仅依赖颜色区分数据；图中保留标题、图例、单位和来源。

项目页顺序为问题、路径、证据、方法与发现、个人贡献、处理难点、来源。每个项目有可分享的独立地址。项目索引提供方向筛选；全局搜索支持关键词与空状态。

图表交互采用原生按钮、选择框和详情折叠。按钮显示当前选中态，更新结果具有可读文本。原图通过原生对话框放大，可用 Escape 关闭。减少动态效果偏好生效。

390、768、1440 像素为主要检查宽度。复杂图表在局部区域滚动，正文不横向溢出；数值同时提供表格表示。界面文案全部中文，保留化学式、统计量和标准技术缩写。
