# 当前版本审查与优化顺序

本次在已完成的作品集上迭代，保留有效内容与交互。基础技术为静态生成页面与少量原生脚本，适合项目深层链接和 GitHub Pages。

## 检查后确认的情况

已有十个项目、研究示例、六规格真实估计图、五张论文原图、模型评价切换、移动导航和搜索。上轮静态检查为 14 页、459 处内部资源和锚点有效。用户本轮明确授权公开上传，随后要求补充报告图表及中文界面。

## 优先处理的十项问题

1. 产业链页只有概念节点，缺少具体报告证据：增加 C3/C4 图表和 PO 数据。
2. 报告表格和原始图需要溯源：分别列明来源、年份、单位和重绘方式。
3. 报告开工率与产量/产能的重算值存在舍入与口径差异：分列展示，不默默更改。
4. 首页和项目标签残留英文：可见文案统一中文，保留规范技术缩写。
5. 项目分散在首页多个段落：新增可筛选的独立项目索引。
6. 窄屏规格图容易缩小：图内独立横向滚动，并保留数值面板。
7. 子目录部署可能破坏资源路径：按实际仓库路径构建并再次审计。
8. 上传检查脚本自身含私人匹配字面量：改成通用正则，原值不进入 Git。
9. 本地提取、出处路径与交付 ZIP 不应被跟踪：扩大忽略规则并逐项检查暂存区。
10. 发布说明仍为待确认状态：本轮沿用已取得授权，部署后记录真实网址及结果。

测试与评审只写实际执行结果；没有运行的性能或无障碍评分不写成已达标。
